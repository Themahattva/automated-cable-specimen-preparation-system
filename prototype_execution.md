# Prototype Execution Steps

Reference format from wire specimen rp.md / ACSPS_Hardware_* files.

Steps:
1. Ingest cable (straightening)
2. Circumferential sheath cut + sleeve removal
3. Insulation slab flatten + longitudinal slitting
4. Dumbbell die stamping
5. HMI monitoring + E-STOP (IEC 62061 Cat 3)
6. Validation: 120 specimens, 142±4 s cycle, Cpk=1.71

No folder files modified; new file only.
